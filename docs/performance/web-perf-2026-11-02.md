## Highest-impact issues resolved

1. **High: blocked Cloudflare script injections produced console errors.** Hostname-scoped response controls now suppress the analytics beacon and JavaScript-detection bootstrap while preserving `script-src 'self'`. Actual HTTP responses supply `frame-ancestors 'none'` and `X-Frame-Options: DENY`; the ineffective meta framing directive was removed. Google Best Practices improved from 92 to 100 on both devices. Zone-wide Bot Fight Mode and other sites' analytics remain unchanged. [Provider scope and rollback](edge-delivery.md) are documented separately.
2. **High: two stylesheets delayed first paint.** A Jekyll post-render hook now embeds the complete canonical Primer subset and compiled compressed Sass in their existing order. This removes two stylesheet requests. The published homepage gzip body is **11,535 bytes**, below the 14-KiB regression budget. Mobile median FCP/LCP fell from the supplied baseline's 1,532 ms to 903 ms, an observed reduction of about 41%; desktop fell from 431 ms to 242 ms. These comparisons describe separate runs, not a controlled causal experiment.
3. **Medium: the responsive portrait transferred excess bytes.** WebP derivatives at 150/300/450 pixels now cost 1,944/4,910/8,604 bytes. The 300-pixel candidate fell from 21,280 JPEG bytes to 4,910 bytes, about **77% smaller**. Width/height, eager discovery, high fetch priority, JPEG fallback, and JPEG Open Graph metadata remain covered by tests.
4. **Medium: perfect scores were not enforced as a retained series.** CI now requires all four displayed scores to equal 100 in every report of a three-run mobile/desktop series. It rejects malformed scores and incomplete series and retains failed reports. Local, hosted CI, live CLI, and Google acceptance records remain distinct.

## Codebase findings

This is a Jekyll/Liquid/Sass site with a vendored Primer subset and vanilla JavaScript, built by the locked Ruby toolchain. Node dependencies provide validation rather than a production frontend framework. There is no React bundle, hydration, bundler tree-shaking, or production polyfill payload to optimize.

`_plugins/inline-styles.rb` consumes the canonical CSS sources and fails full builds for missing/duplicate markers, absent styles, or a closing style token. `_includes/masthead.html` uses the validated portrait stem for both WebP and JPEG URLs. Existing attribute/text escaping, URL validation, color variables, dimensions, and accessible theme-control behavior remain tested. `_config.yml` excludes documentation and validation artifacts while retaining intentional public `.well-known` files.

The observed acceptance applies to this release and canonical hostname. It does not certify all accessibility needs, guarantee search rankings, or guarantee perfect scores under every future network condition or Lighthouse version.
